field notes
  • rx/tx = bytes received/transmitted per second.
  • Per-file sizes: actual = allocated blocks (st_blocks × 512), logical = reported file size (st_size).
  • cpu/memory/network/disk come from the SysStats PUB feed (main port − 1), one snapshot every 2s — Linux servers only (reads /proc); a non-Linux server reads 0.
  • Disk iops = the block device under the data dir; if that device isn't in /proc/diskstats (container/virtiofs/overlay mount) the server reports the host-wide sum of all whole disks instead. 0 can also mean the IO was served from the RAM page cache.
  • ·stale = the feed's snapshot time stopped advancing (collector wedged) or the feed went silent.

About XStore Viewer

version 0.1.0

Desktop viewer for XStore time-series databases. Connect to an XStore server over ZMQ, browse databases and per-year files, query time ranges as a plot or raw table, run min/max/sum/avg aggregates over any range (computed server-side), and watch live server CPU/memory/network/disk stats.
